# 验证状态与能力边界

> 验证边界：大型案例的历史成果是分图集，完整跨块管线合并与该案例配套 PID 尚在修正。分图原生检查通过不等于整图已交付。

截至2026-10-25，本项目已公开工作流和有许可依据的工具；本地真实图纸与知识库验证范围另行记录。本页的历史数字是已核记录摘要，不表示仓库包含私有案例、全部本地依赖或可一键复现完整版。

## 当前32页PID修订的实际状态

本地已生成包含31张工艺页和1张图例页的同案修订候选，完整保留原图例与字段，并按来源合同修改接点和交叉表达。候选级独立检查覆盖22323个原始根图元、7处端点修补、88处已登记拱桥和258个来源箭头。之后在AutoCAD完成DWG写入及5页原生试印；这些是本地专案执行结果，所用专案实现没有整体纳入公开包。

**这套PID尚未通过最终验收。** 实际预览发现两处较大非连接断口没有进入发现器，原因涉及局部搜索距离和轻微倾斜阈值；“已登记的88处桥都通过”不能证明全图没有遗漏。另有两项原生回读差异仍待确认，涉及视口的视觉样式引用位置和视觉样式颜色记录。当前没有全32页原生出图与最终只读回读通过证据，局部裁片也未全部目视完成。

后续须修正发现范围、复核其他未分类断口，关闭实际回读差异，再完成整套原生输出及三重独立最终审核。原失败与未检查范围保留，不能凭候选通过或5页试印成功签发整套图纸。真正合并的连续PFD也仍待完成，历史工段联系总览不作为其替代。

当前版本新增[三重独立审核](../skills/chemical-pfd-pid-cad/references/INDEPENDENT_REVIEW.md)要求，分别用于规划内容和最终文件；不将历史单次独审追认为三审。此次开源包发布与上述未完成图纸分别记录。

## 历史分图及联系总览版的实际检查

最终本地案例包含103设备位号、246接口和31对跨页接续；130条原文流股与10条授权合成公用工程行分别标记，855个实际表字段实例由独立源数据重新计算。原表未载单位或相态保留缺项；文献未注压力基准按明确采用约定处理，不写成原文注明。

当时分图及联系总览版DWG经过独立空白启动文档中的sideDB只读重开；读前/读后哈希一致，严格导出的DXF、实际文字范围、字体解析和绘制顺序与该DWG绑定。审核从冻结原生来源与独立修订合同重算2498个带源身份实体，验证855字段、跨页一致性、24连续拱桥/72ARC以及总览7有向连接、5框/19索引。194来源箭头和7总览箭头独立识别后，与原生3758项实际绘制顺序逐项对照，201箭头位于最前。

1682条真实文字范围未发现该检测范围内的碰撞或裁切候选；20件实际原生PDF各一页，配套20件预览经过内容/解码与哈希检查。主审另外查看全20页联系预览、全部桥区域、两处新增标签与R/S数据表放大。自动包围盒检查和实际墨迹目视分别记录。

原始比较没有伪装成零差异：4个椭圆跨零参数展开经属性与采样点证明等价；2处新增训练标签仅上移8mm；4处真实MTEXT的DXF `^I`与原生tab做精确逐字符对应，保留原串。审查器曾错把原生EXE与托管DLL哈希比较，该失败也保留；修正后分别核对两个对象，不改生产摘要，不为审查表示差异重跑CAD。

实际保存的故障副本覆盖桥半径/半跨度、箭头被线遮挡、非箭头相对次序变化和关闭打印排序；另有源图元、数值、跨端标注和状态错误检查记录。只对实际命中的目标检测器作结论，未把前置拒绝当成所有检测器已验证。

## 明确保留的限制

- 一处源案例支路原有单侧缺口/另一侧T接表达歧义，本轮保留来源并记录，未推造工艺连接；来源保真不等于源工艺设计全面正确。
- 连续拱桥及箭头置顶是本项目采用要求。详桥与总览尺寸经本案空间/视觉审查，不宣称是统一ISO尺寸，也不笼统称HG/T、GB等标准全部符合。
- P&ID的测点/命令关系检查不证明动态性能；没有同案模型/试验就不声称稳定性、保护动作或受限运行通过。
- 部分复杂机械格式、嵌入图像/公式及幻灯片视觉内容仍有读取边界，损坏原生文件隔离。提取记录无文本不等于页面真空白。
- 制造图或未知用途块作为来源案例保留，未核准块不自动成为可直接使用的PFD/PID符号。
- 历史标准切片、案例和字体的许可独立核对，代码许可不覆盖第三方数据。
