# 公开范围与旧引擎退役

公开的是当前工作流可独立维护的部分：五个总分Skill、知识引擎/数据结构、来源追查与回执门控、布局提示、独立几何核验与合成测试、尺寸读取薄层、可公开原生接口源码以及架构/验证方法。

旧工作流和旧绘图主入口不进入新仓库。不能确认独立归属的旧实现不以删除署名的方式重新发布；有价值能力由有明确来源的模块保留，或由独立有界实现承接。根MIT不能覆盖上游的非商业限制。

不随包内容：标准全文、专著、用户原始ZIP/DWG、私人项目数据与切片向量、SHX字体、商业SDK/DLL、模型权重、账号令牌，以及无法脱离私人案例的回放脚本。缺少这些内容时不伪称原本地案例能直接复现。使用者可按知识维护流程导入自己有权使用的资料；资料只用于本地计算不等于有权公开。

公开检查器的支持范围由代码、合成正反例及验证说明共同限定。专门案例中验证过的弧线/拓扑不自动扩大到任意CAD元素、任意共享端口或任意仪表系统。新类型必须明确报未支持，再实现与验证。

发布时区分三类证据：公开可重跑的代码测试；本地历史原生CAD验证的汇总；仍需当前项目专业核对的设计依据。前两类都不是工程签发。
