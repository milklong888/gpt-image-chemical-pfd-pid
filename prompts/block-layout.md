# GPT-image 单块布局请求模板

输入：当前块的来源图例图册（仅合法提供）、对象/接口清单、逐项数据、文字样式参考、图幅及密度限制、所选交叉图例。明确图像只策划布局。

请排列清单中的完整原图例，保持原内部结构和方向；只表达合同中的连接。端口位置和出入方向应留足直段，输出流股有准确终点，过程线与信号线可区分。减少交叉与共线，必需交叉按给定连续桥约定表达。不要发明设备、控制器、参数、口号、编号或源图没有的机械细节。主图只保留必要工程标注。遇到无法可靠还原的图例/文字，在配套说明报告，不用装饰替代。

PFD：使用冻结的逐股编号/方向、T/P/F准确字符串和数据位置清单，安排线旁框、图内物流表或成套续表引用，重点条件在主图可读；不要只画线后把数据推给图外文件。PID：先按物理连接合同安排工艺/公用管道及组合号，再布置信号，不能只剩设备和控制虚线；不照搬案例DN或管道等级。密集处留出明确引线和文字区域，完整保留接续端。

核查者对照对象与接口合同逐项反馈；不要把模型生成的文字当最终CAD字符串。图像通过后再做固定端口/受约束排线/CAD与实际回读。
