# GPT-image 首次流程布局请求模板

先执行[阶段合同](../skills/chemical-pfd-pid-cad/references/IMAGE_INPUT_CONTRACT.md)。本模板用于 `exploration`：默认当前车间或明确工艺范围完整图；只有密度/精度不足才车间内功能块。输入同版对象/有向连接、应画要素及适用标准、准确字段/接口清单、实际国赛整图、清晰局部和完整图例；缺少合格参考时记录检索及回退，不伪造。

按正常化工流程画法生成，借国赛整图的阅读层次、主支线组织、疏密和留白，不照搬其设备或数值。已知图例完整使用，未知对象可按登记范围探索，不能默认用功能方框。塔按已知类型、内件和接口层位，不能从示意横线推真实板数。自由安排位置和走线，不锁蛇形行列、不塞满单框。Image不要求准确字体，留足标签/数据空间。

PFD安排流股号、方向、T/P/F和图内表/续表关联；PID安排实际物理管道及组合号、测控终点；不能借案例创造参数。生成后实际看图、按标准和原图例修正，再准确转CAD并与国赛风格/图例比对。二次优化在首版CAD及必要合并后，使用另一个模板。
