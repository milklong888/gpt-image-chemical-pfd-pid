# 实践发现库内残缺时补齐

先区分已给未读、已读不清、格式未解析和项目未设计/批准。库中没命中不是原件不存在。查登记、页覆盖、父条款/例外、同案图号、原生属性和真实图框，仍不全再沿官方/出版者/同案完整来源追查。

取得完整原件后保存来源/许可/版本与定位；新增切片保留上下文、适用性及冲突，挂相关设备与公共模块。候选补丁由主代理实质核对后进入知识版本；结构校验和哈希不代替正确性。

沿既有LlamaIndex/Docling/LinkML流程更新图谱、模块和真实索引，以原问题/原过滤重检，再用新来源问题查影响。原回执过期，重新绑定受影响计划与图纸。提交失败保留错误和事务状态，不能凭文件存在当发布成功。

已登记来源的单卡修补与新资料导入/旧错误卡替换不同，使用支持对应操作的工具。未知格式或破损文件隔离，不能把容器元数据叫作已读取图纸。盲测期间输入冻结，修补放在批间，不给答题者泄露答案。
