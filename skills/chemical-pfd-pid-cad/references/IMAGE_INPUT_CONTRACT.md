# Image、CAD与布局优化的阶段合同

按用户2026-10-27最新修正，完整绘图顺序为：**理解与按需车间划分 → 检索应画要素/适用国标和行业规则、准备国赛整图/局部/完整图例 → 正常化工流程首图 → 按标准修正并准确转首版CAD、比对国赛风格与图例 → 车间内若切块先完成真实CAD合并 → 三轮审核同版CAD及优化输入 → Image二次只优化排线布局 → 按原图元和冻结合同重画CAD → 原生终验。**

本合同覆盖旧版“先功能块、二次Image之后才首次CAD”顺序。未知图例仍可登记探索，不能把探索外形直接当正式原图例。第二次Image不能提供新的图例、文字、数据或工艺设计。

## 先定用途、范围和是否需要划分车间

- `engineering_pfd` / `engineering_pid`：按本项目适用工程表达，工程图例与准确内容来自已核来源。
- `aspen_native_layout`：用本案Aspen原生图标，不冒称工程PFD国标符合。
- 完整CAD任务使用 `workflow_mode: full_cad`；Aspen只委托前段时使用 `image_layout_only`，看图通过后返回，不为套第二阶段另造CAD。

车间划分**不是每次必做**。按[车间与分块触发规则](LARGE_FLOW_LAYOUT.md)判断：任务已限定单一清楚工艺单元/一个车间时保留范围；涉及多个有依据的车间、明确车间边界或需要分别交付时，先登记设备归属和跨车间流股，再一个车间一个车间生成。工段、页号、功能块不等于车间，缺归属证据时用明确的工艺范围，不能为了排版虚构车间。

默认按正常化工流程画法生成本范围完整图，阅读顺序、主支流、回流和能源关系清楚，以适用国赛整图学习图面层次；不固定左右塔位或逐行坐标。只有本车间信息密度、完整图例/接口保真度、标注容量或生成精度不足时，才在车间内按功能和真实接口切块。禁止为了塞满单框而蛇形往返、缩字或压缩间距；实在难以完整生成时采用小块CAD后真实拼接。

## 前置检索：既查怎么画，也查必须画哪些要素

先按行业/工艺服务、图种、设计阶段和交付要求检索；实际执行现有RAG的packet/query，读取命中切片、父条款、条件/例外、表头/图注和必要原页。不能仅查询设备符号，也不能直接凭模型记忆列一份“国标清单”。GB/GB/T、行业标准、项目要求与竞赛案例分别记录，标准目录身份、正文已读和项目适用是不同事实。

从适用条文推导本图的**要素清单**：设备/编号、物料与能源及流向、流股条件和图内表、界区与跨页接续、图例/单位、图签/版次，以及PID按范围应有的管道号/规格、仪表功能/位置与信号等。该列举只是查找主题；每项是否必须、条件触发、可省略例外及落图位置，均回到采用的原条款。沿用已有信息台账记录“要素→标准条/表/页或项目依据→适用/未决→本案数据来源→图上位置→检查方式”，不用另造重复数据库。

资料没给某项时先追原件，再有依据推导；不得把“要求表示某设施”误读成授权新增未经设计的设备、控制或保护系统。已有值、来源缺值和标准适用未定分开。第一关从条款反查清单漏项，准确落CAD后和交付前再从清单核真实图面，不能只证明台账里有。

库内切片/上下文残缺先溯源补库并重检；尚未解决的符号/画法缺口可以限定首图探索，不能称标准已通过。项目工况和有向连接仍来自本案依据，不随图例或案例继承。文献压力未注基准按总控的绝压采用规则保存两层来源记录。

## 国赛整图、局部和图例都进入Image输入

按[国赛优先与塔画法](COMPETITION_LEGENDS_AND_TOWERS.md)实际看并提供三类参考：**同图种适用的国赛整图**学习阅读层次、疏密和图面组织；**清晰局部**学习标注、接管和线型表达；**完整设备图例图册**绑定本图对象。不能只给文字描述或图例小图而漏掉整图风格依据。图片须清楚、带来源和用途；国赛身份未独立核实时照实记录，未找到适用案例时记录检索和回退来源，不伪造参考图。

用现有 `references` 的 `applicable_reference` 绑定整图/局部，`symbol_atlas` 绑定完整图例；来源页与裁片、对象对应和实际附图都在第一关核。整图只借画法，案例里的设备数量、位置模板、回路和数值不能移植。字体不作为Image门槛，准确字体在CAD/Aspen落字时核。

## 第一阶段：正常流程首图，随后准确转CAD

`stage: exploration`。冻结本次范围、对象、有向连接、准确标签/数据与应画要素；逐对象登记未知符号或画法。已有合适国赛图例必须随实际图片传入，未知外形可以探索，不由程序默认塞普通方框。有来源的矩形设备或包界保留其语义。

Image自由安排正常化工流程的排布、走线和留白，按本车间或明确工艺范围生成；大而密才按上述规则车间内切块。过程先后不等于纸面坐标，真实回流保留，避免无依据的蛇形密排。首图为 `candidate_unstandardized`，不直接交付。

首图生成后实际看图，把图例、接点、连接和信息问题对应到适用标准及原件。已知拓扑错误先修；可确定性重建的问题记入CAD修正清单，未知外形须找到适用原图例/画法后替换。随后按有用布局**制作首版CAD**：完整原图元、真实端口、准确旗标/流股参数、PID管道组合号及已核字体逐项写入；不逐笔临摹错误像素。此阶段允许制作可审的CAD候选，不必先等第二次Image；未经确认的未知项不冒充定稿。

## 首版CAD：国赛风格/图例比对，必要时先合并

并排打开选用国赛整图、局部/图例和首版CAD原生输出，比较主支线层次、设备疏密、留白、标签/参数旗组织及符号完整性。逐对象核塔型/内件和接点，不能只评价“像不像”。图例必须与所选来源一致；风格借鉴不能覆盖标准或改变本案语义，精确字体/数值仍按本案核。

如果车间内拆了功能块，先逐块完成准确信息和接口核对，再在CAD中**真实合并成该车间的首版完整图**，接实跨块管线、回流和能源联系。对合并图再次比对国赛风格与图例，核跨块两端ID/方向/工况、重叠和丢字。只有图片拼贴、宏观联系图或待接线的模块清单不能进入下述二次优化；单图无需合并时记录不需合并的范围依据。

## 三轮独立审核：核已落CAD及二次优化输入

三轮审阅同版首版CAD/原生预览、实际合并或无需合并的证据、冻结合同、国赛参考与图册及优化输入；候选作者不为自己签三个结论。改动后重审受影响范围。

|轮次|实际核对|
|---|---|
|依据与符号|要素标准是否检索并落实，设备/图例/塔内件是否与来源一致；国赛整图与局部的适用性，案例与规范分清|
|画法与信息|实际端点、方向、流股/管道标注及归属、字体入框；国赛风格与标签/线型组织比对；车间内跨块管线确已合并|
|整图与优化边界|从来源反查漏项/多项，冻结设备图例、拓扑和数据，列可调整位置/通道；确认实际送入的是同版CAD预览，优化要求仅限排线布局|

三轮只批准这版CAD作为排版优化基底及相应输入，不证明未来Image或最终CAD已经通过。重要工程未知、未关的硬错误和应审未审范围不能用美化掩盖；获准审阅稿的未决值仍按原批准原值/待核表保留，不在Image中补造。

## 第二阶段：CAD之后的Image仅优化排线布局，再重画CAD

`stage: cad_layout_refinement`，仅用于 `full_cad`。必须实际提供已存在的首版CAD文件身份、同版清晰预览、真实合并或无需合并的证据，以及三轮审过的布局优化说明。把CAD预览以 `cad_baseline` 真正送入Image，同时给已选国赛整图/局部和完整图例；不能拿第一次Image冒充CAD预览。

Image只建议设备/模块位置、阅读层次、管线通道、转折、间距和标注留白。**只参考排线布局**：不采用它更换的设备符号、内件、接口服务/层位、设备或流股数量、有向拓扑、控制配对、编号、文字、数值、单位、字体或线型标准。若建议镜像/旋转违反真实接口或物理约束就拒绝；位置变化不能当成允许改变接口含义。

实际看二次图，逐对象/逐边检查是否仍可映射到冻结合同。只记录接受的位置/通道建议，拒绝的图片细节不进入重画；布局建议导致错接、漏股或破坏塔层位时退回调整。随后**用首版已核原图元、数据与字体重新绘制/调整CAD**，重新落实端口、受约束排线和标注，不整张临摹二次图片，也不从图片OCR回填信息。

重画后再次对比原合同及国赛图例/风格，复验标准要素、真实连接、穿设备、重叠、折线、字体和原生输出，再执行第三关。二次Image通过只表示布局建议可用，不能代替重画CAD或最终验收。

Aspen `image_layout_only` 仍在前段看图后返回，可按实际问题修正首图但不运行这里的CAD后优化流程；没有CAD基底不得称完成 `cad_layout_refinement`。后续另有完整CAD任务时再按该范围进入。

## 字体与标签：先实际看案例，再写明怎么画

**Image不要求字体，不以字体相似度或源字体文件作为生图门槛。** Image只安排图例、标签位置和足够的文字空间，保留可辨认的对象对应。实际字体、准确字符、字高/宽度/对齐及字形入框由后续CAD/Aspen写入和原生输出检查负责。早期说明中“Image必须附字体图”或“Image字体通过”不再作为必需条件；可选图片参考也不构成字体验收。

标签和字体不能只查到一段摘要就自行决定。按下面自然语言步骤执行，不另造一套仅填通过布尔值的表：

1. **先辨标签用途并实际看原图。** 区分流股编号、F/T/P参数框、跨页/界区接续、设备位号/名称、PID管道组合号及仪表圈内文字。通过检索优先定位同案图例页和同用途局部；不足再看合适的国赛/工程案例。必须用实际图像查看能力打开原页总览和足够清晰的局部，读到所属管线、邻接支路、旗形/框、字段排列、单位/表头和接续去向。单独读PDF文字层、检索摘要、文件名或标签轮廓，不算已看案例。
2. **说清学什么、为什么适用。** 记录实际看过的来源ID、页/句柄及图像位置，用几句自然语言说明采用的旗形/框、字段顺序、对齐、引线和归属规则，以及不采用的部分。同案和匹配用途优先；案例用于表达学习，不能借用它的温压流量、DN、等级或控制参数，也不能因获奖免核适用标准。不同用途的编号旗、参数旗、接续符不能混作一种标签。
3. **在实际写字前核源样式。** 用已看案例确认目标外观，将候选样式与本项目采用依据对应，案例字体不自动成为项目字体；再读取匹配原生CAD文字样式、字体及BigFont依赖、字高/纸面比例、宽度、倾角和对齐；按文字角色选用，不能从扫描图猜字体名或把一个样式铺到所有圈内/框内文字。只有图像而无确切字体依据时继续溯源或沿项目已采用样式，不默认换系统字体。缺适用案例/字体时保留具体未决项，可继续不声称定稿的探索，但实际标注不能按“案例已核”放行。
4. **用自然语言交代标签操作。** 例如：“本股沿用刚核对案例中的流股编号符号，放在所属直管段旁；附近有多条线时，短引线明确落到本股，不串到邻线。把同一股的温度、压力和流量按所选案例字段顺序写进参数区，并保留核实的单位。空间不足时调整新框、换行或改成明确关联的图内数据表，不能缩字压窄。跨图端另用已选接续符，写清去向和对应页，不能拿它代替流股编号。CAD写入沿用已核字体/对齐，文字与框之间留足实际可读的空间。”将其中的对象和表达替换为本次已选案例，不把这段例子当作固定旗形、固定坐标或全部图种的标准。
5. **落图后回看案例和实际输出。** 审阅者须重新打开选用案例局部，与当前原生输出并排核文字层级、旗/框、排列、引线终点及真实管线归属；同时查本图准确字段和采用条款。再核实际加载字体、中文/数字/单位与特殊符号、真实字形包络、框内留白及正常打印可读性。样式名称相同、文字插入点在框内、程序写入成功都不足以通过。Image的示意字不进入这个字体通过判断。

这些步骤分别接入生图前的案例阅读、三轮标准修正中的表达方案审核，以及实际落字后的最终验收。已有同版已核案例可明确复用；用途、字体、旗形或表达方式改变就重新查看受影响案例。Aspen仅布局任务返回标签放置说明、案例引用与准确内容映射，字体落实仍由上游写入时检查。

## 信息插入：先定字段、Image留位、首版CAD准确写入

信息内容与旗标画法继续以[流股落图与PID管道](STREAM_AND_PIPE_ANNOTATION.md)为唯一详细规则，不能因分块/总排布而省略。已有信息优先读取溯源，有依据才能推导；未知不填零、不由Image创造。授权训练值另场景逐字段标S，不变成工程来源值。

1. **Image前定内容和归属**：逐对象/流股/管段确定准确字符串、单位、基准、工况、来源及状态，并关联所属设备/真实管线、预定编号符号和参数区/表页。不能只给一串数值，或等总图完成才决定需要插什么。
2. **Image安排位置和容量**：给已核图例、已看案例中的标签放置说明和字段清单，预留设备标签、编号旗、参数框、引线及图内表空间；不要求Image复现字体。图像中的文字/数值仅作布局示意，不通过OCR回填数据，不凭画出了一个旗形就算标注完成。
3. **首图或必要小图通过布局审核后，准确落图**：由CAD实施读取选定完整符号，创建可编辑标记/表格，按稳定ID写入准确文字或块属性，把标记或引线绑定所属真实管段。编号旗、参数旗和接续符分别处理；实际插入点受已核布局约束，不凭空白位置随意放置。完整CAD任务先完成首版准确信息、接口及原生核对；如分块先真实CAD合并，再交Image只优化排线布局，之后按原合同重画。
4. **插入后双向对账**：源数据→CAD文字/属性→实际打印；图中每项新增→对象/管段→数据来源。核错配邻线、缺项、重复造号、单位/工况混用、表图不一致、字体出框和打印不可见。仅数据台账齐全或文字实体存在不足以通过。
5. **总排布与拼接后复核**：整块移动时同步变换标记和引线，复查跨块同股身份、数据版本与图页引用。总图可减少重复细节，但保留模块/设备身份、跨块流股号和方向、关键条件及详图/表页索引；不能把正式成套PFD应报数据全部移到图外。

|图种|本项目按依据准备的信息|落实位置|
|---|---|---|
|PFD|设备位号/名称，物料与能源路径、流股号/方向、应报T/P/F；组成、相态、热负荷/功率等按服务和资料适用性确定|编号关联真实流线；数据采用线旁参数框、图内流股表或有明确引用的成套续表；主图保留重点条件|
|PID|真实管道及管道组合号/规格、设备与管口、阀件、仪表位号/功能、测点/信号/执行器终点；等级边界及保温伴热等按依据|标在所属管段、对象或明确引线处；关联同版管线表/图例，不用控制虚线代替物理管道|

不机械给每根短线段重复编号或T/P/F，也不规定所有行业统一旗形。分流后各支路与混合后出口按真实流股身份和采用规则核对，物料流股号与PID管道组合号分别映射。

Aspen `image_layout_only` 仍停在前段：返回已审布局、可用标注空间以及准确标签/字段/单位、目标对象/流股和表页映射，由上游实施写入并验收。它不执行本段CAD步骤，也不能称准确信息已落入原生模型。

## 总排布后及交付前：衔接只是其中一项

标准修正三轮核已落CAD及二次布局优化输入；不能代替最终实际图纸的[第三关](INDEPENDENT_REVIEW.md)。按本图采用的规则逐项验同一最终版本：

|检查范围|实际核对|
|---|---|
|适用标准与图例|行业/图种适用、版本、条/表/图、父条件/例外、项目采用；最终符号、线型、编号、文字/图幅等是否实际落实。国标、行业标准及项目约定不混称；不能仅用“符合国标”一句自评|
|工艺与控制语义|设备和物料/能源路径不漏不增，冷热侧/介质不串；PID测点、信号种类和执行器归属与已给控制意图一致|
|信息完整与一致|准确字段及其来源、单位/基准/工况；编号旗、参数旗、管道号、表页引用与真实对象对应；跨图数据同版，不用图外台账代替图面|
