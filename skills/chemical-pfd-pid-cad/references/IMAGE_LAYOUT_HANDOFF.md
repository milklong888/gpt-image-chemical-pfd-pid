# Image 布局前段：供 Aspen 调用并返回

## 触发与停止点

Aspen 流程任务需要新 PFD 布局、整体重排或复杂流程分块时，调用总控 Skill 的 `image_layout_only` 范围。执行检索、第一关内容审核、ImageGen 生成及第二关看图反馈，通过后返回原 Aspen 主任务。这里的图块是生成的布局图片，不是 CAD BLOCK。此模式是 Skill 的工作范围约定，不是已有的自动 Aspen 排版 API。

仅查压力、保全既有图形、只读审图或实施仍有效的已核布局时，不额外触发新图生成。未限定前段的完整 PFD/DWG 请求仍走完整绘图流程。

## Aspen 提供的内容

复用当前项目已有合同，至少能追到同一版本的案例/导出身份和阶段、Aspen block/stream ID、有向连接、进料/产品/回流与能源接口、拟显示的流股数据及单位/压力基准。尚未求解的骨架须标明阶段和缺项，不伪装为计算结果；必要资料能读取或推导的先补齐，不要求为排版重新计算全流程。

明确用途是 Aspen 原生流程图的排布参考，还是报告中的工程 PFD。两者分别使用已核的 Aspen 图标参考或完整适用的工程图例；保留模拟块与实物设备的已有映射，不能把 FSPLIT、SEP、Calculator 等模拟对象自动画成新增实体设备。图像不决定设备选型、连接、工况、控制关系或物理管口。Aspen 的抽象连接端口与设备真实喷嘴分别记录。

调用时同时说明原任务接手者、目标图幅/阅读层次、字体与准确标签要求、需要的分块范围、允许调整的位置/方向及禁止修改的语义。可使用以下简短约定，不另造一套工程台账：

```text
mode: image_layout_only
caller/return_to: 当前 Aspen 主任务
source_contract: 同版案例/导出及已有内容台账
drawing_use: Aspen 原生排布参考 / 报告工程 PFD
stop_after: image_review
```

## 只执行前两关

1. 读取总控和 [PFD专项](../../chemical-pfd-drawing/SKILL.md) 中适用的检索、标准、图例与信息表达规则，再按 [第一关](INDEPENDENT_REVIEW.md) 核内容、来源、准确文字与 Image 提示的一致性。库内残缺先溯源补齐；影响布局或拓扑的错误退回调用者的合同，不让图像选择工艺版本。
2. 使用实际 ImageGen 生成布局图。按信息密度决定单块或按 [分块流程](LARGE_FLOW_LAYOUT.md) 逐块生成；大流程先冻结双端 ID、方向、数据版本及回流/能源联系。需要块间总体排布时可生成总布局参考，但不自动扩大为 CAD 拼接。
3. 执行第二关，实际查看每块及跨块关系：图例/对象不漏不增，接管或抽象接口方向与用途正确，流向与出流终点明确，跨块流股双端一致，没有穿设备、线重叠、错误交叉语义、断头、无意义折线及不可读标注。反馈具体问题后修改并重看；同因重复失败先诊断或细分。原生图标用途不能冒称机械管口已核。
4. 只在当前图片、范围和跨块对账都通过时返回。图像中的错号、错值、误连或其他可见硬错误须先修正；本模式不能把它们记成“后面 CAD 会修”而放行。像素目视不等于精确几何或工程验收，图片仍只提供布局依据，准确内容来自原合同。

## 返回给 Aspen

返回已保存的 Image 图块及块 ID、对应对象/流股映射、采用的布局与必要的块间相对位置/通道意图、跨块接口清单、准确标签和数据台账引用、两关的查看范围及具体反馈/回检记录。复用现有记录即可，不为格式额外建空表。保留提示与图片身份，项目资产放在约定输出目录，不能仅留临时链接。

返回结论用 `layout_review_passed` 或 `blocked`，明确仅覆盖图像布局。工具不可用、未实际看图、必要范围未审或错误未关时，返回具体阻塞与已完成范围，不声称已生成或通过。已通过块可保留，但局部通过不能代表整项通过。

**第二关结束立即交回 Aspen；不继续固定 CAD 端口、自动路由、DXF/DWG 重建、原生 CAD 出图或第三关 DWG 验收。** 其他参考中这些后半段步骤在本模式不执行。若内容变更，回到第一关并重查受影响图块；布局变更重查第二关及跨块关系。

Aspen 主任务接纳返回包后，按原任务决定是否在 Aspen 中落实坐标/标签或用于报告。实际修改和保存重开仍由 Aspen 既有操作与验收规则负责；没有已验证的坐标实施能力时如实交回缺口，不能把图片通过说成 APW/BKP 布局、计算或最终交付已通过。正式工程图的第三关只在另有该交付范围时执行。
