# 特大流程分块生成与拼接

整图生成难以保留文字、设备或端口精度时触发；按工段/功能及真实物料、能源、信号接口切块，不仅按设备数设固定阈值。先冻结源页→块映射、每块设备/符号、跨块源端/目标端、ID、方向、工况及对页。

## PFD优先小图，车间整体布局后置

完整PFD按顺序执行：内容与跨块接口冻结→逐模块Image布局和反馈→小图CAD落实准确图例、接管、流股编号标记、F/T/P参数标记及接续符并核对→仅把已核模块边界/接口交Image生成车间宏观排布→宏观审核→同车间CAD接续/拼接→原生回读和打印复核。宏观图负责相对排布、方向、回流通道和模块间连接，不承担准确造字或替代小图/真实CAD数据检查。不得把“先宏观Image，最后统一插旗”当执行顺序。

最多一个有来源的车间；工段不等于车间，需用总图、设备布置或明确归属确认边界。跨车间保留有依据的界区/接续和双端流股身份，不强拉成一张图。Aspen `image_layout_only` 是例外：只做所需小图、准确标签/接口合同与宏观布局Image，第二关通过即返回，不运行CAD；不改变完整PFD的CAD前置条件。以上PFD顺序不降低PID对实际管道、仪表和信号的逐项检查。

逐块使用GPT-image并反馈：是否漏/加设备、图例是否完整、管口方向/终点、标签密度、控制关系和可读性。图像生成错误由来源合同纠正，不采纳画出来的新编号或连接。精度不够继续细分；避免切断完整本地控制回路。

整体块间排版仍可交给GPT-image提案，主代理按同一接口合同拼接。局部通过不代表全图通过：检查跨块遗漏/重复/错接/反向、回流和能源联系，双端ID/数据/对页逐项对账。只有单端的标记不能称已接续。

固定端口后实施受约束CAD图元，禁止无意义折返和穿体，必要交叉按本项目采用的连续桥。对真实合并图重新查重叠、箭头、文字与字体/线宽；原生DWG重开及整页/局部PDF验收后交付。

保留每次图像输入合同、输出、拒绝/采纳理由、CAD候选和当前文件证据。不能把缩小整图冒称分块，也不能把三类检查冒称三次图像重画。

交付形态必须与要求一致：要求完整合并流程图时，块间真实过程线必须接入最终CAD并核到两端；页面拼贴、独立联系总览与仅匹配跨页标签均不能替代。未要求联系图时不额外以它交付。PFD与PID分别列交付件，不能用一个图种冒充另一个。
