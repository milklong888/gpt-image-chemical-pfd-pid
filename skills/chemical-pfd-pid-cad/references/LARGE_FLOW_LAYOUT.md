# 车间划分、正常流程生成与必要时分块拼接

按[阶段合同](IMAGE_INPUT_CONTRACT.md)执行。先识别实际工艺范围，以正常化工流程图生成完整单元/车间图为默认；车间划分与车间内部功能分块是两个判断，均不机械执行。

## 何时划分车间

|情况|处理|
|---|---|
|单一明确单元，或本来就限一个车间且可清楚表达|不额外划车间，直接画本范围完整流程|
|任务跨多个已证实车间，或用户/项目明确要求按车间交付|先读取总图、设备归属、图签和项目边界，建立设备归属及跨车间接口；一个车间一个车间生成|
|范围很大但车间归属不明|先溯源确认；只能确定功能范围时按明确功能范围作图并记车间归属未决，不把工段/页/块假称车间|
|只因设备多、回流多或线密|这只能触发精度与分块评估，不能单凭数量创造物理车间边界|

每次整体生成和工程拼接最大一个已核车间；跨车间保留准确接续/去向、流股身份、方向及同版数据。全厂总览如另有要求可以单独做导航，不替代车间图。PID可因详细信息需要在同车间内分多页，不将“一车间一车间推进”误解为全部PID强塞一页。

## 何时在车间内切功能块

先用同类国赛整图、目标图幅/打印比例、完整图例和标注量判断是否能正常整体表达。策划已能明确预见精度不足，或首图反馈出现设备/接口反复丢失、标注无空间、跨线混淆及必须密集折返才装得下时，才切功能块；无须为形式重复失败。没有固定设备数门槛。能通过调整图幅/留白保持清楚时优先整体；无法稳定生成时按功能与接口切块并拼接。

紧耦合设备、回流/控制局部尽量同块。每块冻结对象、完整图例、块内边及外部端口；跨块保存ID、源端/目标端、方向、类型、工况/数据版本、页块号及接续标记。不能把绘图拆分边界变成真实包界、车间界或新增设备。标准要求与信息覆盖按最终完整范围核，不因分块丢掉必需项。

## 正确顺序：首版CAD合并在二次Image之前

1. 检索应画要素和标准、国赛整图/局部/图例；确定车间或明确工艺范围，必要时冻结车间内分块接口。
2. 按正常化工流程生成本车间首图；仅必要时逐功能块首图。Image自由排布，不指定蛇形行列，保证主流、支路、回流和留白。
3. 依据首图有用布局及已核标准、原图例制作准确CAD，落实真实端口、旗标/流股数据、PID管道与组合号和字体，核几何并比对国赛风格/图例。
4. 若已分块，先在CAD中按真实接口合并到同车间完整首版，实际连接全部跨块物料/能源/信号边，记录变换并同步端口、法向、文字和引线。无需合并的整图记录范围即可。核对合并图及实际原生预览，不能只拼图片或只匹配标签。
5. 三轮审核首版完整CAD、标准要素、国赛比对和同版布局优化输入；然后把**实际合并后CAD预览**交Image二次优化排线布局。
6. 二次图只采纳位置、走线和留白建议；保留原图例、接口语义、数据、字体及拓扑，按原生素材重画CAD，再验整图与交付。

不能回到“先小图CAD→另生宏观Image→首次CAD合并”的旧顺序；二次Image的基础必须已经是本车间首版完整CAD。整块移动同步接口/文字，若优化涉及块内排布，回验该块和全部受影响跨块边。

Aspen `image_layout_only` 是范围例外：使用同样的车间/分块判断、标准与案例输入，只返回已核布局和准确字段/接口映射，不自动制作CAD，不把前段图片拼合称真实CAD合并，也不声称完成CAD后的二次优化。

## 拼接和重画后均须验

设备/流股不漏不重，跨块两端身份、方向、数据工况和去向一致，回流与能源关系完整；逐条核真实端点/轴线、首末段、全线穿设备、重叠、多余折线、断口与非连接交叉。必要交叉采用本项目约定的连续拱桥，并如实记录标准采用差异。

国赛整图与局部用于比较疏密、主支线层次、符号、标签组织和留白，不能继承其数值、设计或错误；准确字体、真实字形入框、线宽/颜色、箭头顺序及图内数据在实际CAD和原生打印中复核。保存关闭重开DWG，回读实体及字段，与同版PDF/预览核对。

要求完整合并流程图时，最终CAD必须具有真实跨块过程线；页面拼贴、额外车间联系图或分图目录不算完成。流程规则不代表已经有任意多页通用生成器，未支持拓扑如实列缺口。
