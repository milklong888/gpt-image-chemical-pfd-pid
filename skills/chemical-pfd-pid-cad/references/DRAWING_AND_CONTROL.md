# 图种信息与控制次序

|图种|按项目深度体现|不能据此代替|
|---|---|---|
|PFD|设备与位号、物料/能量流向、边界/跨页去向、特征操作条件、同号流股T/P/F及必要组成/相态/基准|管道施工与保护设计|
|PID|技术连接、设备与管口、管线编号/规格关联、阀件、仪表/信号/测点/执行器、取样排放、公用工程和包界|设备制造、强度及动态验证|
|设备条件图|已核设计条件、尺寸/方位、视图、管口表、内件及技术条件|凭图像新增制造数据|

来源R、推导D、授权合成S与缺项分开。流股表与图号逐项对应，同工况才合并；操作值、设计值、控制SP、报警和联锁定值不互换。图中留必要信息，算法名、验收统计和长解释放伴随记录。

控制设计先列目标、硬约束、扰动、可测量量与可操纵自由度。联合安排产量点、库存、压力/能量及循环稳定化，再处理质量和监督层；热不稳定或快速质量硬约束须优先稳定，不能机械套“压力→液位→温度”。检查组分去向、回流/补加/排放和调节余量，不把全部回流固定。

逐回路记录CV目标、测点代表性、MV实际物理路径、唯一最终命令所有者、上/下层SP及证据。串级输出进入内环SP；协调选择器与两个控制器并行直写阀不同。内外环速度比较必须同一指标/工况；图形完整与静态自由度不证明动态稳定。

设计顺序、整定顺序与开车顺序分别记录。保护/联锁/PSV存在性、定值、排放与失效位回同案依据，不从教材或案例补造。动态模型/试验缺失时只交候选结构。

复杂新增控制可按三组反馈组织：①目标/产量/库存/能量；②测量—控制—执行器配对与冲突；③扰动、饱和、公用故障和模式切换。轮数按任务约定，不能替代实际检查或宣称固定三轮就正确。

方法参考：[Skogestad 全厂控制章节与勘误](https://skoge.folk.ntnu.no/publications/2012/skogestad-plantwide-control-book/)、[2004 控制结构设计](https://skoge.folk.ntnu.no/publications/2004/control_structure_design_cce/cce04_skogestad.pdf)、[2000 全厂控制综述](https://skoge.folk.ntnu.no/publications/2000/plantwide_review3/plantwide_review3.pdf)。按当前问题读适用条件，文献不提供本项目定值。
